# 🤝 Contribuindo para Quantum Spin Study

Obrigado por considerar contribuir! Este projeto é open-source e todas as contribuições são bem-vindas.

---

## 📋 Como Contribuir

### 1. Reportar Bugs
- Use o [GitHub Issues](https://github.com/Tretabolt/quantum-spin-study/issues)
- Descreva o bug claramente
- Inclua passos para reproduzir
- Screenshots são bem-vindos

### 2. Sugerir Melhorias
- Abra um Issue com a tag `enhancement`
- Descreva a melhoria em detalhes
- Explique por que seria útil

### 3. Contribuir com Código

```bash
# 1. Fork o repositório
git clone https://github.com/SEU_USUARIO/quantum-spin-study.git

# 2. Crie uma branch
git checkout -b feature/nova-feature

# 3. Faça suas alterações
# ...

# 4. Commit
git commit -m "feat: descrição da feature"

# 5. Push
git push origin feature/nova-feature

# 6. Abra um Pull Request
```

### 4. Padrões de Commit

Usamos [Conventional Commits](https://www.conventionalcommits.org/):

```
feat: nova funcionalidade
fix: correção de bug
docs: documentação
style: formatação
refactor: refatoração
test: testes
chore: manutenção
```

Exemplos:
```
feat: adiciona simulação de spin-1/2
fix: corrige cálculo de TMR na junção túnel
docs: atualiza guia de montagem do EPR
```

## 📝 Estilo de Código

### Python
- Siga [PEP 8](https://peps.python.org/pep-0008/)
- Use type hints quando possível
- Docstrings em todas as funções
- Comentários em português ou inglês

### Markdown
- Use headers consistentes
- Inclua diagramas quando possível
- Links funcionais
- Tabelas bem formatadas
