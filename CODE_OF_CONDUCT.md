# 📜 Código de Conduta

## Nossa Pledge

No interesse de promover um ambiente aberto e acolhedor, nós como contribuidores e mantenedores nos comprometemos a tornar a participação neste projeto uma experiência livre de assédio para todos.

## Nossos Padrões

Comportamentos que criam um ambiente positivo incluem:

- Usar linguagem acolhedora e inclusiva
- Ser respeitoso com diferentes pontos de vista
- Aceitar crítica construtiva
- Focar no que é melhor para a comunidade
- Mostrar empatia para com outros membros

Comportamentos inaceitáveis incluem:

- Uso de linguagem sexualizada
- Ataques pessoais
- Assédio público ou privado
- Publicar informação privada sem permissão
- Outros comportamentos antiéticos

## Responsabilidades

Os mantenedores do projeto são responsáveis por:
- Clarificar padrões de comportamento
- Tomar ação corretiva quando necessário
- Remover, editar, ou rejeitar conteúdo inadequado

## Escopo

Este Código de Conduta se aplica a todos os espaços do projeto, incluindo Issues, Pull Requests, e comunicações externas.

## Aplicação

Instâncias de comportamento abusivo podem ser reportadas abrindo um Issue.
