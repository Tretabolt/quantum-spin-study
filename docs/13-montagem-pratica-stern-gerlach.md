## Passo 2: Preparar o Pó de Magnetita

### 2.1 Moer a Magnetita

```
Magnetita (pedra)
      │
      ↓
┌─────────────┐
│  PILÃO      │  ← bater até virar pó
│  ┌─────┐    │
│  │pedra│    │
│  └─────┘    │
└─────────────┘
      │
      ↓
   pó grosso
      │
      ↓
┌─────────────┐
│  PENEIRA    │  ← separar grão fino
│  ┌─────┐    │
│  │~~~~~│    │
│  └─────┘    │
└─────────────┘
      │
      ↓
   pó fino (~0.3mm)
```

**Dicas:**
- Moer por 10-15 minutos
- Peneirar sobre folha de papel
- Grão ideal: areia fina (0.2-0.5mm)
- Muito fino dispersa no ar
- Muito grosso não separa bem

### 2.2 Testar se Funciona

```
Teste rápido:
1. Pegar um pouco de pó
2. Aproximar ímã
3. Se atrai → FUNCIONA! ✓
4. Se não atrai → magnetita ruim, trocar fornecedor
```

## Passo 4: Montar os Ímãs

### 4.1 Configuração dos Ímãs

```
VISÃO FRONTAL:
┌─────────────────────────────────────┐
│                                     │
│  ÍMÃ SUPERIOR (S para baixo)       │
│  ┌─────────────────────┐            │
│  │ ▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓ │ ← polo S  │
│  └──────────┬──────────┘            │
│             │                        │
│        campo concentrado             │
│        (ponta ou borda)              │
│             │                        │
│  ┌──────────┴──────────┐            │
│  │ ░░░░░░░░░░░░░░░░░░ │ ← polo N  │
│  └─────────────────────┘            │
│  ÍMÃ INFERIOR (N para cima)         │
│                                     │
└─────────────────────────────────────┘

DISTÂNCIA: 4-6 cm entre os dois ímãs
```

### 4.2 Criar o Campo Não-Uniforme

**Opção A: Ímãs normais (funciona parcialmente)**
```
Dois ímãs retangulares:
- Superior: S virado pra baixo
- Inferior: N virado pra cima
- Distância: 5cm
- Resultado: campo mais forte no centro
```

**Opção B: Ímã + ponta de ferro (melhor!)**
```
Ímã em cima + parafuso/ponta embaixo:
- Ímã: S virado pra baixo
- Parafuso: ponta virada pra cima
- Campo concentra na ponta!
- Resultado: gradiente forte
```

**Opção C: Dois ímãs com formato diferente (ideal)**
```
Superior: ímã de bloco (reto)
Inferior: ímã cônico ou em V
- Campo mais forte na ponta
- Gradiente máximo
```

### 4.3 Fixar os Ímãs

```
Estrutura com papelão ou madeira:
┌─────────────────────────────────────┐
│  ┌─────────────────────────────┐    │
│  │  Suporte superior           │    │
│  │  (papelão furado)           │    │
│  └──────────┬──────────────────┘    │
│             │                        │
│         ┌───┴───┐                    │
│         │ ÍMÃ S │                    │
│         └───────┘                    │
│             │                        │
│           5cm                        │
│             │                        │
│         ┌───────┐                    │
│         │ ÍMÃ N │                    │
│         └───┬───┘                    │
│             │                        │
│  ┌──────────┴──────────────────┐    │
│  │  Suporte inferior           │    │
│  └─────────────────────────────┘    │
└─────────────────────────────────────┘

## Passo 6: EXPERIMENTO!

### 6.1 Teste de Controle (SEM ímã)

```
1. Encher funil com pó de magnetita
2. Posicionar detector (papel) abaixo
3. Abrir abertura do funil
4. Observar: pó cai em linha reta
5. FOTOGRAFAR
6. Marcar no papel: "SEM CAMPO"
```

### 6.2 Experimento (COM ímã)

```
1. Posicionar ímãs (configuração escolhida)
2. Encher funil novamente
3. Abrir abertura
4. Observar: pó deve separar!
5. FOTOGRAFAR
6. Marcar no papel: "COM CAMPO"
7. Medir distância entre trilhas
```

### 6.3 Comparar Cristais

```
Repetir para cada cristal:

## Dicas Importantes

### Local
- **Sem vento** (pó dispersa fácil)
- **Superfície limpa** (fácil de ver o pó)
- **Boa iluminação** (para fotos)
- **Longe de eletrônicos** (ímãs fortes)

### Timing
- Preparação: 1 hora
- Experimento: 30 minutos
- Análise: 30 minutos
- **Total: ~2 horas**

### Segurança
- **Ímãs de neodímio:** cuidado com dedos (beliscam forte)
- **Pó de magnetita:** não inalar (usar máscara se possível)
- **Mãos sujas:** magnetita mancha (usar luvas)

## O que Esperar

Se tudo der certo (e com magnetita, VAI dar certo), você vai ver:

```
SEM CAMPO:          COM CAMPO:

    │                 │
    │                 │ ●  ← trilha 1
    ●                 │
    ●                 │
    ●                 │
    │                 │ ●  ← trilha 2
    │                 │
  papel             papel
```

**Isso é o Experimento de Stern-Gerlach em escala macroscópica!**

A separação em duas trilhas prova que:
1. Os spins estão alinhados (momento magnético)
2. O campo não-uniforme exerce força diferencial
3. A quantização do momento angular é real!
